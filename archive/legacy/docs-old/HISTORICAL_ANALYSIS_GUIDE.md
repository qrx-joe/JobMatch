# 历史数据分析功能使用指南

## 功能概述

新版本支持**历年数据对比分析**，可以：
- 加载多年度报名人数统计
- 预测今年上岸分数线
- 分析竞争趋势（上升/下降/稳定）
- 计算个人上岸概率
- 给出报考策略建议

---

## 文件结构

```
项目目录/
├── config_full.yaml          # 配置文件（新增历史数据配置）
├── demo_complete_pipeline.py # 主程序（支持配置文件模式）

        ├── 2023年统计.xlsx
        ├── 2024年统计.xlsx
        └── 2025年统计.xlsx
```

## 配置文件说明

### 1. 数据文件配置

```yaml
data:
  # 当前年份岗位表路径（包含多sheet，每个sheet一个地市）
  jobs_file: "2025年岗位表.xlsx"

  # 输出目录
  output_dir: "reports"
```

### 2. 历史数据配置

```yaml
historical_data:
  # 是否启用历史数据分析
  启用: true

  # 当前年份
  当前年份: 2025

  # 历年统计数据文件
  历年统计:
    2023:
      文件路径: "data/historical/2023年统计.xlsx"
      上岸分数线: 65.5        # 该年实际上岸分数
      平均竞争比: 15.2
    2024:
      文件路径: "data/historical/2024年统计.xlsx"
      上岸分数线: 68.0
      平均竞争比: 18.5
    2025:
      文件路径: "data/historical/2025年统计.xlsx"
      上岸分数线: null      # 当前年份还未结束
      平均竞争比: null
```

### 3. 分析选项配置

```yaml
historical_data:
  分析选项:
    # 预测今年上岸分数（基于历年趋势）
    预测分数: true

    # 竞争趋势分析
    竞争趋势: true

    # 报考策略（conservative-保守/normal-正常/aggressive-激进）
    报考策略: "conservative"

    # 你的预估分数（用于计算上岸概率）
    预估分数: 70.0
```

## 历年统计表格式

每个年份的统计表应包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 单位名称 | 岗位单位名称 | 济南市财政局 |
| 填报信息人数 | 报名人数 | 60 |
| 初审通过人数 | 初审通过 | 45 |
| 缴费人数 | 最终缴费人数 | 40 |
| 招募人数 | 招录人数 | 5 |

**注意**：单位名称需要与岗位表中的单位名称能够匹配。

## 使用方式

### 方式1：配置文件模式（推荐）

```bash
# 确保 config_full.yaml 已配置好路径
uv run demo_complete_pipeline.py

# 或使用指定配置文件
uv run demo_complete_pipeline.py config_full.yaml
```

### 方式2：命令行模式（传统）

```bash
# 仅岗位表
uv run demo_complete_pipeline.py 岗位表.xlsx

# 岗位表 + 当前年统计
uv run demo_complete_pipeline.py 岗位表.xlsx 统计表.xlsx
```

### 方式3：模拟数据演示

```bash
# 无参数时自动使用模拟数据
uv run demo_complete_pipeline.py
```

   ```bash
   uv run demo_complete_pipeline.py
   ```

## 数据准备建议

### 如果没有历年数据

可以：
1. 先只用当前年数据运行（功能降级为普通匹配）
2. 逐步收集往年数据完善分析
3. 预估分数线可以参考往年公布的进面名单

### 单位名称匹配问题

如果历史数据中的单位名称与岗位表不完全一致，系统会尝试：
1. 精确匹配
2. 前6个字符模糊匹配

建议保持命名一致性，或手动调整统计表中的单位名称。

## 常见问题

**Q: 没有历史数据可以使用吗？**
A: 可以，将 `historical_data.启用` 设为 `false`，系统会跳过历史分析，仅做基础匹配。

**Q: 预估分数填多少合适？**
A: 建议根据模拟考试成绩填写，或参考往年分数+5~10分。

**Q: 上岸概率怎么算的？**
A: 简单模型：
- 你的分数 > 预测分10分 → 95%
- 你的分数 > 预测分5分 → 85%
- 你的分数 ≈ 预测分 → 70%
- 你的分数 < 预测分 → 逐步降低

**Q: 预测分数准确吗？**
A: 基于历年趋势线性预测，仅供参考。实际分数受报名人数、考生水平等多因素影响。
