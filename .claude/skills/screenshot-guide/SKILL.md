I cannot view images or screenshots. When user provides a visual artifact:

1. STOP immediately and state: "我无法查看图片。请用文字描述你看到的内容。"
2. Ask for specific details based on issue type:

   **UI/布局问题：**
   - 哪个元素位置不对？
   - 当前位置和期望位置
   - 浏览器类型和窗口大小
   - 是否只在特定分辨率出现

   **错误弹窗/控制台：**
   - 完整错误文字（复制粘贴）
   - 错误出现的操作步骤
   - 浏览器控制台是否有红字

   **数据展示问题：**
   - 哪一列/哪个字段显示异常
   - 预期值 vs 实际值
   - 涉及的数据条数

3. Do NOT guess image content or make edits based on assumed visual information.
4. If user insists on screenshot-only communication, ask them to use OCR or paste text.
