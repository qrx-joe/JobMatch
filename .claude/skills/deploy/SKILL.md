description: Build and deploy JobMatch frontend to Vercel
---

Build the JobMatch frontend and deploy to Vercel:

1. Change to frontend directory: `cd D:/code/JobMatch/webapp/frontend`
2. Run build: `npm run build`
3. If build succeeds, deploy: `vercel --prod`
4. Report the deployment URL
5. If build fails, report the error details and do not deploy

Scope: Only operate on `webapp/frontend`. Do not modify backend or other directories.
